01 · 能力

把重活交给机器，把选择留给人

  1. 对等 C/S自己指挥自己，也能指挥别人

    每个实例既是 C 又是 S。Linux 本地回环走同一条 muxed WebSocket，不开本地特权通道；远端 PWA 以同一协议直连。

  2. NDJSON + CQRS一行一提交

    命令写 NDJSON，查询读内存投影。全局递增 id 跨 UTC 分文件不归零，空洞与损坏可截尾恢复。

  3. Agent 执行可取消，可追踪

    基于 Agent Framework，消息记账、generationId 取消、推理过程分开展示；失败与取消分状态回显。

  4. PWA 纯前端不持密钥，不跑模型

    浏览器只做界面与 WebSocket；IndexedDB 按 instanceId 存连接，Service Worker 仅缓存静态壳。

  5. 内容寻址附件SHA-256 定址

    分块上传、哈希校验、引用随消息入库；删除以 tombstone 记账，不改历史。

  6. TOML 唯一权威热更新，冲突可判

    配置唯一来源为 TOML 明文，热更新与重写语义明确；监听端点与 TLS 边界收敛。

02 · 原则

十二条第一性原理，十六条自动判断

  1. 01纸感优先暖纸基底，墨蓝只点缀 5% 以内；分割靠 hairline，抬升靠 ivory。
  2. 02一色到底全站单强调色 #1B365D；tag 仅两档 tint，不开第二彩色。
  3. 03字重克制Serif 承重，400/500 两档；标题不加粗，靠字阶与留白分层。
  4. 04对话为王会话与消息永远视觉主位；机制与设置退后，不抢焦点。
  5. 05同一协议本机与远端走同一 WebSocket 面；不为本机开后门。
  6. 06一行一真相NDJSON 一行一原子提交；内存投影可随时重建。

04 · 问答

常见问题

万象与 Kelivo 的关系？
Kelivo 为灵感来源，万象为 clean-room 独立实现。产品名、协议、配置与数据模型均不复用原文案与源码。
数据存在哪里？如何恢复？
三件套即全部真相：TOML 配置、NDJSON 事件日志、附件目录。重启后自动重建投影。
PWA 需要装什么？
不需要。现代浏览器打开即用；离线壳由 Service Worker 缓存静态资源，业务数据不缓存。
如何连接远端服务器？
输入地址与令牌直连；首次可走 6 位配对码，服务端终端输出，限流 5 次/分钟。
